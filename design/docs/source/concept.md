# Agent Wires concept

web puzzle game about orchestrating agent workflows.
each level has input and output and a set of agents.
agents have inputs and outputs (like data, positive/negative feedback, etc) and player connects them with "wires".
no actual llms, all is scripted.
funny tasks with weird results when agents are connected wrong.
vibe - thechnocratic high stakes, saving humanity through dumb tasks.

visual: a retro-futuristic, 1970s NASA mission control, Bauhaus minimalistic, Kubrick's 2001: A Space Odyssey, engineering aesthetic.
