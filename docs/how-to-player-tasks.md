# Player tasks

Short recipes for things you do while playing. New to the game? Start with [Your first shift](tutorial-your-first-shift.md).

## See the whole board

- Phone or tablet: pinch to zoom out. Drag on an empty part of the board to pan.
- Computer: hold the control key and turn the scroll wheel to zoom. The wheel alone, or two fingers on a trackpad, pans.

Zooming out stops where the whole board fits the window. Zooming in stops at a comfortable jack size. While a run plays, the board is locked: no pan or zoom until the report closes.

## Move or remove a wire

- Move: press one end of a placed wire, near its jack, and drag it to another jack of the same side.
- Remove: drag one end and drop it on no jack.
- Replace: tap an output jack that already has a wire, then tap a new input. An output jack holds one wire, so the old wire goes.
- Take back the last plug, move, cut or reset: UNDO.
- Start the order over: RESET returns it to its opening wiring.

## Find an order's hand-written results

Each order hides three hand-written results: what happens when it is wired wrong in a certain way. Wire it wrong on purpose and run it. A new result prints in the incident report and is filed. The order list shows "Results n of 3" for each order.

Finding every result of an act earns that act's results commendation.

## Light the 2ND WIRING lamp

Most orders show a 2ND WIRING lamp. Win one, then win it again with a wiring that works differently: agents in another order, a loop instead of a chain. When two of your wins count as different, the order's 2ND WIRING lamp lights and stays lit.

## Meet a par

An order with a par shows a WIRES lamp, a TIME lamp, or both. Win it with no more wires than its wire par, or in no more beats than its time par. The report prints "Par met." and the lamp lights. Repair orders count MOVES instead: the fewest changes to fix the overnight wiring.

## Look at your commendations

Press MEDALS. COMMENDATIONS shows every act's three medals: earned ones in colour, the rest with how far you are. The MEDALS key counts the medals you hold, as 3/18.

## Read old reports

Press ORDERS, then ARCHIVE. The archive lists each order's results and its filed reports. Tap a filed report to print it again.

## Keep your progress on another device

Progress stays in the browser you play in. To move it:

1. On the order list, press SAVE CODE. The teletype prints the code with COPY. Copy it.
2. On the other device, open the game, then press LOAD SAVE CODE on the order list.
3. Paste the code and press READ. "SAVE CODE READ" prints.

The code merges into what that device already holds: an order won on either stays won, and each best score is the better of the two. A wrong or damaged code prints "CODE NOT READ" and changes nothing.

The game also prints your save code at the end of each act.

## Play offline

Open the game once while online and let LOADING finish. From then on it opens with no connection, from the files it kept. When you are online again, it looks for a new version.

A browser that keeps no site data plays as usual but forgets your progress when the page closes. The order list then says "THIS TERMINAL KEEPS NO RECORDS. COPY YOUR SAVE CODE." Copy your code before you close the page.

## Turn the sound off

Throw the AUDIO switch, the first key on every screen. Its lamp goes dark and every sound stops, key clicks too. On an iPhone, the silent switch also mutes the game.

## Share a report

Press SHARE on any report, then:

- TEXT: copies the report as text, with the game's link, and prints "COPIED". A phone also opens its share sheet. A browser that refuses the copy prints the text selected, with "SELECT AND COPY": copy it yourself.
- PICTURE: makes a picture of the board with a QR code that opens the game. It saves the picture as a file and prints "SAVED"; a phone that can share files also opens its share sheet. A browser that can do neither shows the picture with "PICTURE ON SCREEN. SAVE BY HAND."
