# Transmission Control 2: user stories

Approved with Brief, 28 Oct 2026.

## Stories

- S1. As new player, I want to start playing from link with no account or install, so that I can try game in short break.
- S2. As player, I want to wire order's agents and run batch, watching each item travel, so that I learn from what goes wrong.
  - Same wiring, same result, every time: no chance.
- S3. As player, I want every run to end in written report naming what each agent did, so that each failure is joke and clue.
- S4. As optimizer, I want each win scored against par and my best kept, so that leaner second wiring is worth finding.
- S5. As player, I want campaign of six acts, each adding department, with repair orders later, so that puzzles stay fresh to end.
- S6. As player, I want my reports filed and achievements earned for what I found, so that I collect misfires.
- S7. As player, I want to share report as text or picture carrying game's link, so that friends can laugh and play.
- S8. As player, I want progress kept, movable to another browser by save code, and playable offline, so that I never lose my place.
  - No account, no cookies.
- S9. As phone player, I want every order playable by touch in portrait or landscape, so that game plays anywhere.
  - Every order fits from 360 by 640 phone to 1920 by 1080 screen.
- S10. As owner, I want anonymous counts of each order's starts and finishes, and game at one public address, so that I can share it and judge how far players get.
  - Counts carry no player or session id.

## Coverage

Experimenter, player who learns by trying:

- Start from link: S1
- Wire and run: S2
- Reports: S3
- Par and best: S4
- Campaign: S5
- Archive and achievements: S6
- Sharing: S7
- Saving and offline: S8
- Touch and phone: S9

Optimizer, player who replays to beat par:

- Par and best: S4
- Second wirings in achievements: S6
- Every other outcome: same stories as experimenter.

Owner:

- Public address and player counts: S10
- Playing it: same stories as player.

## Gaps

Owner agreed to leave both out, 28 Oct 2026:

- Stuck player has only report as clue; hints left for later, as design says.
- Sound on or off is only setting; no larger text or reduced motion.
- out: hints, languages other than English, accounts, leaderboards, ads, anything sold.
