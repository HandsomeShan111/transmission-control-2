# Stories: Transmission Control 2, first playable release

Brief: the Brief, first playable release.

## Stories

- S1. As a new player, I want to start playing from a link with no account or install, so that I can try the game in a short break.
- S2. As a player, I want to wire an order's agents and run the batch, watching each item travel, so that I learn from what goes wrong.
  - Same wiring, same result, every time: no chance.
- S3. As a player, I want every run to end in a written report that names what each agent did, so that each failure is a joke and a clue.
- S4. As an optimizer, I want my win scored against par and my best kept, so that a leaner second wiring is worth finding.
- S5. As a player, I want a campaign of six acts, each adding a department, with repair orders later, so that the puzzles stay fresh to the end.
- S6. As a player, I want my reports filed and achievements earned for what I found, so that I collect the misfires.
- S7. As a player, I want to share a report as text or a picture carrying the game's link, so that friends can laugh and play.
- S8. As a player, I want my progress kept, movable to another browser by a save code, and playable offline, so that I never lose my place.
  - No account and no cookies.
- S9. As a phone player, I want every order playable by touch in portrait or landscape, so that the game plays anywhere.
  - Every order fits from a 360 by 640 phone to a 1920 by 1080 screen.
- S10. As the owner, I want anonymous counts of each order's starts and finishes, and the game at one public address, so that I can share it and judge how far players get.
  - Counts carry no player or session id.

## Coverage

- Start from a link: S1
- Wire and run: S2
- Reports: S3
- Campaign: S5
- Archive and achievements: S6
- Sharing: S7
- Saving and offline: S8
- Touch and phone: S9
- Par and best: S4

Optimizer (a player who replays to beat par):

- Par and best: S4
- Second wirings in achievements: S6
- Every other outcome: same stories as the experimenter.

Owner:

- Public address and player counts: S10
- Playing it themself: same stories as a player.
